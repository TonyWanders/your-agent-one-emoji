A program that writes one emoji to `/output/entry.txt`, for the make.fun
competition
[Your Agent in One Emoji](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given
as the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 1 character, inside the 1 to 16 gate.

## The entry

```
🐝
```

## Why the bee

An agent works in the background, does the task, and brings the result
back while its human does something else. That is what a bee does, and
"busy as a bee" is the idiom everyone already knows. It reads instantly
at small size, it says something specific about how the agent behaves,
and it is far from the obvious robot or smiley half the field will
send.
